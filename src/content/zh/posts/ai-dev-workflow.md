## AI 不是替代开发者

很多人对 AI 辅助开发的误解是"让 AI 帮我写全部代码"。实际上，AI 在开发流程中最有价值的位置是：**减少重复劳动，让你专注在业务逻辑和架构决策上**。

## 我的工作流

### 第一步：定义规则

在动手之前，先明确需求。不是"做一个功能"，而是"这个功能的输入是什么、输出是什么、边界条件有哪些"。

### 第二步：让 AI 出方案

把规则给 AI，让它出技术方案和接口设计。你审核方案是否合理，不合理就推翻重来。

### 第三步：AI 写代码，你验收

AI 根据确认的方案写代码。你不需要逐行审查，但需要：

- 跑一遍功能，确认核心路径正常
- 检查安全相关的代码（认证、输入校验）
- 确认没有硬编码的密钥和配置

```bash
# 构建验证
npm run build

# 安全审计
npm audit --production
```

## 关键经验

- **不要让 AI 一次性做太多** — 拆小任务，每步验收
- **保持代码简洁** — AI 容易过度设计，要及时砍掉不必要的抽象
- **核心逻辑写测试** — 算钱、权限、数据处理的代码必须有测试覆盖
