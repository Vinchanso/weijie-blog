# 研究发现与风险记录

## 字体授权审查（2026-08-07）

### 安全可用（OFL 1.1 授权，免费商用）
| 字体 | 用途 | 授权 |
|---|---|---|
| Noto Serif SC（思源宋体） | 中文正文 | SIL OFL 1.1 |
| LXGW WenKai（霞鹜文楷） | 中文正文备选 | SIL OFL 1.1 |
| Newsreader | 英文正文 | SIL OFL 1.1 |
| JetBrains Mono | 代码块 | SIL OFL 1.1 |

### 不可使用（侵权风险）
- 微软雅黑、苹方 — 系统字体，不能作为 Web Font 分发
- 方正系、汉仪系 — 需要商业授权
- 来源不明的"免费下载"中文字体

### 技术注意
- 中文字体完整版 10MB+，必须做子集化（只打包实际用到的字）
- 用 font-display: swap 避免字体加载期间文字不可见

## 双语方案决策（2026-08-07）

### 否决方案: 同页双语堆叠（上面中文下面英文）
原因:
- 页面过长，移动端体验差
- SEO 对混合语言页面处理不好，两种语言排名都受影响
- 写作维护成本高
- 破坏极简风格

### 采纳方案: 语言切换
- URL: /zh/posts/xxx 和 /en/posts/xxx
- hreflang 标签区分
- 写作灵活，可先写一种语言
